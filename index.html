MiniMax: more subagents isn't better
A MiniMax Code builder walks through Anthropic's advice to fold subagents back into one main loop: split only along context lines, never by team or problem type, and treat any subagent you keep as a tool. Tool picking degrades past 30 to 50 tool definitions, so group tools by user intent. Plans and decisions belong in a progress doc rather than only in the chat, and code review should run in a clean context that sees only the diff, requirements and test results.
